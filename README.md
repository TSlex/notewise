# Notewise

Локальный MIDI-тренажёр чтения нот для клавишных. Работает в Chrome и принимает вход с обычной MIDI-клавиатуры.

## Запуск на Windows

Дважды кликни [notewise-local.bat](notewise-local.bat) и выбери `Start`. Приложение откроется по адресу `http://127.0.0.1:3000`.

Тем же файлом можно:

- остановить сервер — `Stop`;
- проверить, работает ли он — `Status`;
- снова открыть приложение в браузере — `Open in browser`.

Для запуска нужен установленный Node.js. Зависимости уже находятся в проекте; если папка `node_modules` когда-нибудь будет удалена, один раз выполни `npm install` из этой папки.

## Режимы

- Чтение нот: несколько попыток до показа ответа.
- Чтение на скорость: нота движется к линии, а темп адаптируется к результату.

История сессий и настройки хранятся локально в Chrome.
