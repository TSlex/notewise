**Последняя сверка с кодом:** 31 июля 2026  
**Репозиторий:** `TSlex/notewise` · ветка `main` отслеживает `origin/main`  
**Назначение:** локальный Chrome-тренажёр для освоения чтения нот на клавишных, рассчитанный прежде всего на игру с MIDI-клавиатуры и минимальное использование мыши.

## Что пользователь ожидает от приложения

- Интуитивная практика чтения нот в скрипичном, басовом или смешанном ключе.
- Настройка диапазона: 1, 1½ или 2 октавы; сессии на 10, 20 нот либо без конца.
- Ответ MIDI-клавиатурой; экранное пианино остаётся запасным способом ввода.
- Верный ответ сразу открывает следующую ноту. В обычном режиме две ошибки не раскрывают ответ, третья раскрывает его и затем переключает задание.
- Быстрые настройки с клавиатуры, звук приложения с выключателем и громкостью, светлая/тёмная тема, время и история занятий.
- Одна расширяемая база для будущих тренажёров (аккорды, интервалы, ритм и т. п.), а не отдельные приложения.

## Готово сейчас

### Тренажёры

1. **Чтение нот** (`study`): одна натуральная нота на стане; верная клавиша переключает задание автоматически. После третьей неверной попытки показывается имя ноты.
2. **Чтение на скорость** (`flow`): нота движется слева направо к пунктирной линии. Верный ответ ускоряет следующую ноту на 6%, пропуск замедляет на 12%; границы времени — 1,8–8 секунд.

В обоих режимах доступны скрипичный, басовый и смешанный ключи; пресеты диапазона и длины сессии. Смена режима, ключа, диапазона или длины сохраняет начатую непустую сессию в историю и запускает новую.

### Ввод, звук и управление

- **Web MIDI:** `navigator.requestMIDIAccess()` читает Note On, Note Off и Note On с velocity 0 как отпускание. Подключение запрашивается при открытии и повторяется кнопкой статуса. Целевой браузер — Chrome; реальное оборудование нужно проверять вручную.
- **Экранное пианино:** мышь/тач; диапазон MIDI 36–84, белые и чёрные клавиши, подсветка нажатой и раскрытой ноты.
- **Звук приложения:** Web Audio API, треугольный осциллятор; его можно выключить, если звук уже идёт из самой MIDI-клавиатуры. Громкость 0–100%.
- **Клавиатурное управление:** `Esc` открыть/закрыть настройки, `Space` пауза, `R` начать новую сессию, `M` сменить режим, `T` сменить тему, `S` переключить звук, `+`/`−` изменить громкость. В настройках: `↑`/`↓`, `←`/`→`, `Enter`, `Esc`.

### Интерфейс и данные

- Тёмная и светлая темы; визуальный стиль вдохновлён интерфейсом MusMath, но реализован собственным CSS.
- Слева — текущая сессия и до 16 прошлых: тип, время, точность, число нот; у скоростного режима также пропуски и финальный темп.
- Таймер не идёт на паузе, в настройках и после завершения сессии.
- Всё состояние клиента хранится только в `localStorage` Chrome:

  | Ключ | Данные |
  | --- | --- |
  | `notewise.settings.v1` | режим, ключ, диапазон, длина сессии, звук, громкость, тема |
  | `notewise.sessions.v1` | последние 16 завершённых/архивированных сессий |

Нет учётных записей, синхронизации, серверной БД или аналитики.

## Технологии и команды

- React 19 + Next 16, запускаемые через Vinext/Vite; TypeScript; CSS без UI-библиотеки.
- Требуется Node.js `>=22.13.0`.

```powershell
# Установка после удаления node_modules
npm install

# Разработка вручную
npm run dev -- --host 127.0.0.1 --port 3000

# Проверка перед передачей
npm test
npx tsc --noEmit
npm run lint
```

Для обычного локального запуска в Windows дважды открыть `notewise-local.bat`. Он держит PID в `.notewise-local.pid`, журнал в `notewise-local.log` и не выставляет сервер в сеть. Эти временные файлы игнорируются Git.

## Границы и известные нюансы

- Сейчас тренируются только **натуральные ноты**; чёрные клавиши доступны на экранном пианино, но генератор их не задаёт.
- В скоростном режиме неверная клавиша не останавливает ноту: она продолжает движение до правильного ответа или тайм-аута.
- История создаётся при завершении фиксированной серии, `R`, изменении параметров упражнения или уходе со страницы; пустая сессия не сохраняется.
- Автозвук может требовать первого пользовательского жеста из-за политики браузера.
- `layout.tsx` всё ещё содержит публичный URL прежнего Sites-развёртывания в метаданных. Это не влияет на локальную работу, но его следует пересмотреть перед новым публичным выпуском.

## План развития

Приоритеты не являются реализованными функциями.

1. **Аккорды:** новые типы вопросов и тренажёр на основе `TrainerModule`; определить правила проверки одновременного/арпеджированного ввода, обращения, типы аккордов и обратную связь без мгновенного показа ответа.
2. **Новые модули:** интервалы, ритм, гаммы/ладовые упражнения — добавлять отдельными папками в `app/trainers/`, переиспользуя MIDI, аудио, таймер и историю.
3. **Настройки модулей:** вынести общие параметры из `TrainerSettings` и добавить модуль-специфичные параметры так, чтобы переходы и сохранение истории не ломались.
4. **Качество практики:** настройка числа попыток, выбор конкретных нот/диапазона, статистика по проблемным нотам, экспорт/очистка локальных данных.
5. **Надёжность и доступность:** ручные тесты с реальной MIDI-клавиатурой, обработка нескольких MIDI-входов, улучшение мобильного/клавиатурного UX и более поведенческие тесты.
6. **Поставка:** при необходимости отделить неиспользуемую шаблонную облачную инфраструктуру либо настроить осознанное развёртывание. Для локального продукта облачный хостинг не требуется.
